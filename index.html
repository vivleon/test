03. 3 Core Solutions 핵심 기능 상세

① AI Admin (행정) Core
  • 전자출석/요약: 태깅·이벤트 로그 → NEIS 입력용 요약 자동 생성(복붙/다운로드).
  • AI Safety Pack: 사고 발생 시 음성(STT) → 육하원칙 경위서/보고서 변환.
  • 문서 표준화: 기관 표준 문구/금지 표현 가이드 적용(민원 예방).
  • 평가 증빙 OS: 평가지표별 사진/문서 자동 분류 및 저장.
② Triple Check (안전) Logic
  • Triple-Check: [교실(하원) → 버스(탑승) → 집(하차)] 3단계 추적.
  • Cross Check: "게이트 아웃 OK, 탑승 미확인" 시 즉시 경보.
  • 버스 연동 최소화: 기존 업체 로그를 수동 업로드/조회 형태로 수용 가능(기관별 상이성 흡수).
  • Manual Fallback: 태그 분실 시 교사/기사 앱에서 [이름 터치]로 수동 체크 (예외처리).
* 법규 리스크(하차 확인 의무/제재): 법제처 보도자료 기준 (Ref-6)
③ Parent Link (학부모 앱) App
  • 폐쇄형 인증: 초대코드 → 자녀 매칭 → 관리자 승인 3단계.
  • 이동 이벤트 알림: Gate-Out/Boarding/Drop-off 푸시 + 예외(미탑승/미하차) 즉시 알림.
  • 서류 디지털화: 투약의뢰서/결석계/귀가동의서 앱 제출 (종이 서류 0).
  • Clean AD: 지역 기반 교육정보(수익 모델) — 파일럿에서는 기본 OFF.

Endpoints (concept)

- POST /auth/invite/claim   { inviteCode, deviceInfo } -> session
- POST /auth/refresh        -> session

Transit
- POST /transit/events      { TransitEvent } -> { accepted: true }

Idempotency
- 모든 POST는 header: Idempotency-Key 사용 권장
- server: upsert by (orgId, idempotencyKey)
Offline Queue & Idempotency Reliability

Client-side algorithm (pseudo)

enqueue(event):
  event.eventId = ULID()
  event.idempotencyKey = hash(deviceId + event.eventId)
  persist(localQueue, event)

sync():
  for event in localQueue order by occurredAt:
    resp = POST /transit/events with Idempotency-Key
    if resp.ok:
      mark(event, "SENT") and remove from queue
    else if transient:
      retry with backoff
    else:
      mark(event, "FAILED") show operator action (Driver/Teacher)

server_receive(event):
  if exists(orgId, idempotencyKey): return 200 (idempotent)
  validate(role, event.type)
  write TransitEvent
  run reconciliation rules -> maybe create Alert
  write AuditLog
  return 200
* 오프라인 구간이 잦은 환경을 전제로 “신뢰성(Resilience)”을 KPI로 관리

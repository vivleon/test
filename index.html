01. Project Canvas 문제 정의 및 핵심 솔루션

🚫 Pain Points (문제)

  • 인계 공백 (Hand-over Gap): 교실에서 나왔으나(하원), 버스에 타지 않은(미탑승) '이동 구간' 사각지대 존재.
    [Ref-1] 2024 유치원 안전사고 9,802건 중 '통학/이동' 사고 상존
  • 행정 업무 과중: 교사 업무 40%가 단순 기록/입력(투약, 귀가동의, 안전일지).
    [Ref-4] OECD TALIS 2024: 한국 교사 주당 행정업무 6시간
  • 도입 비용 장벽: 5학급 미만 소규모 유치원은 고가 장비(비콘/리더기/DTG) 설치 불가.
    [Ref-5] DTG+LTE 비용: 초기 40만 + 월 1.6만/대

💡 Scholix Solution (해결)

  • AI Admin Core: 음성 한 줄로 [안전일지+투약의뢰+보고서] 자동 생성.
  • Triple-Check Logic: [교실하원 → 버스탑승 → 버스하차] 3단계 추적으로 누락 원천 봉쇄.
  • Zero-Hardware: 교사/기사 스마트폰 = NFC 리더기. (도입비 0원).

03. 3 Core Solutions 핵심 기능 상세

① AI Admin (행정) Core
  • 전자출석부: 태깅 데이터 → 법정 서식(NEIS 연동형) 자동 매핑.
  • AI Safety Pack: 사고 발생 시 음성(STT) → 육하원칙 경위서/보고서 변환.
  • 평가 증빙 OS: 평가지표별 사진/문서 자동 분류 및 저장.
② Triple Check (안전) Logic
  • Triple-Check: [교실(하원) → 버스(탑승) → 집(하차)] 3단계 추적.
  • Cross Check: "게이트 아웃 OK, 탑승 미확인" 시 즉시 경보.
  • Manual Fallback: 태그 분실 시 교사/기사 앱에서 [수동 체크] (예외처리).
③ Parent Link (앱) App
  • 안심 알림: "탑승/하차" 푸시 알림 + 폐쇄형 인증(초대코드).
  • 민원 디지털화: 투약의뢰서, 결석계, 귀가동의서 앱 제출 (종이 서류 0).
  • Clean AD: 지역 기반 교육정보(수익 모델).

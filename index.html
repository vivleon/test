01. Project Canvas 문제 정의 및 핵심 솔루션

🚫 The Problem (현장의 고통)

  • 안전 사각지대: 하차확인장치(버스)와 교실 출석부(NEIS)가 연동되지 않아 '중간 실종' 위험 존재.
  • 행정 업무 과중: 교사 업무의 40%가 단순 기록/입력. (투약, 귀가동의, 일지, 품의 등)
  • 초기 도입 장벽: 5학급 미만 소규모 유치원은 고가의 하드웨어/비콘 설치 불가.

💡 Scholix Solution (해결책)

  • AI Admin Core: 음성 한 줄로 [안전일지+투약의뢰+가정통신문] 자동 생성.
  • Dual Gate Logic: 버스(이동) + 교문(도보) 태깅 데이터를 크로스 체크하여 100% 추적.
  • Zero-Hardware: 선생님 폰이 곧 리더기. 도입비 0원, 즉시 사용 가능.

03. 3 Core Solutions Scholix 핵심 기능 상세

① AI Admin (행정) Core
  • 전자출석부 자동화: 태깅 데이터가 법정 서식에 자동 매핑 (유아학비 청구 근거).
  • AI Safety Report: 사고 발생 시 음성(STT) 기록으로 경위서/보고서 자동 생성.
  • 평가 증빙 OS: 평가지표별 사진/문서 자동 분류 및 저장.
② Dual Gate (안전) Patented
1. Gate-to-Gate 버스 승하차 + 현관(선생님폰) 통합 관제
2. 누락 방지 (Cross Check) "하차 완료 vs 입실 미확인" 시 즉시 알림
3. 예외 처리 (Manual Fallback) 태그 미지참 시 앱에서 [수동 출석] 버튼 1회 클릭으로 데이터 통합 완료.
③ Parent Link (학부모) App
  • 실시간 안심 알림: "1호차 탑승", "정문 통과" 등 위치 기반 정확한 알림.
  • 민원 업무 디지털화: 투약 의뢰서, 결석계, 귀가 동의서 앱 제출 (종이 서류 0).
  • Clean AD: 지역 학원/병원/커머스 정보 제공 (수익 모델).

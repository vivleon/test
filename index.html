01. Project Canvas (개요)

🚫 Problem (문제)

  • 이중 출결 관리: 버스 승차 명단과 교실 출석부가 따로 관리되어 '누락 사고' 위험 상존.
  • 행정 비효율: 등·하원 시간 수기 기록 → 나이스(NEIS) 입력 → 유아학비 청구의 복잡한 절차.
  • 비용 장벽: 5학급 미만 소규모 단설 유치원은 고가 장비 도입 불가.

💡 Solution (해결)

  • All-Pass Tagging: 버스(통학) + 유치원 현관(도보) NFC 태깅으로 출결 데이터 100% 통합.
  • Smart Attendance: 태깅 즉시 '전자출석부' 생성 및 유아학비 산정 일수 자동 계산.
  • Teacher's Phone as Reader: 별도 리더기 없이 선생님 스마트폰을 태깅 리더기로 활용.

🎯 Target & Strategy

02. 기회비용 및 기대효과 (Data Analysis)

[기준 모델] 5학급 / 버스 1대 운영 유치원 기준 분석

💰 1. 비용 절감 효과

하드웨어/설치비/통신비 제거로 연 55% 비용 절감.

* 단말기(50만)+설치(10만)+통신비 vs SaaS구독

⏳ 2. 행정 업무 시간 단축

출석부/일지/평가 증빙 자동화로 일 70% 시간 단축.

* 기존 수기 60분 → 자동화 18분

🚑 3. 안전사고 골든타임 확보

  • 기존 (위험):
    사고 발생 → 원 복귀 후 기억 의존 작성 (45분 소요).
    * 골든타임 초과로 민원/소송 대응력 상실
  • EduProof (안전):
    현장 음성 녹음 → 3분 내 리포트 자동 생성.
    * 정확한 타임라인 증빙 확보

03. 3대 핵심 솔루션 (기능 고도화)

① Core (행정/안전) UP
  • 전자출석부 자동화: NFC 태깅 데이터가 '전자출석부' 서식에 자동 매핑 (유아학비 청구 근거 자료).
  • AI Safety Pack: 사고 경위 음성(STT) 기록 및 법정 보고서 변환.
  • 평가 증빙 OS: 교육청 평가지표별 사진 자동 분류.
② Smart Attendance NEW
1. 등하원 통합 관리 (Gate Tagging) 버스 승하차뿐만 아니라, 유치원 현관에서 선생님 폰(Kiosk모드)에 가방 태그 시 '등원 완료' 처리.
2. 원아 누락 방지 (Cross Check) "버스 하차 10명 vs 교실 입실 9명" → 즉시 알림 발생 (미입실 아동 추적).
3. 예외 처리 (Manual Fallback) NFC 미지참 시 앱에서 [수동 출석] 처리 (데이터 통합).
③ Parent (학부모) UP
  • 실시간 안심 알림: "1호차 탑승" / "유치원 정문 통과" 구분 알림.
  • 민원 업무 디지털화: 투약 의뢰서, 결석계, 귀가 동의서 앱 제출 (종이 서류 제거).
  • Clean AD: 지역 학원/병원 정보 제공 (수익화).

05. 실행 로드맵 (Roadmap)

03. 3 Core Solutions 핵심 기능 상세

① AI Admin (행정) Core
  • 전자출석/요약: 태깅·이벤트 로그 → NEIS 입력용 요약 자동 생성(복붙/다운로드).
  • AI Safety Pack: 사고 발생 시 음성(STT) → 육하원칙 경위서/보고서 변환.
  • 문서 표준화: 기관 표준 문구/금지 표현 가이드 적용(민원 예방).
  • 평가 증빙 OS: 평가지표별 사진/문서 자동 분류 및 저장.
② Triple Check (안전) Logic
  • Triple-Check: [교실(하원) → 버스(탑승) → 집(하차)] 3단계 추적.
  • Cross Check: "게이트 아웃 OK, 탑승 미확인" 시 즉시 경보.
  • 버스 연동 최소화: 기존 업체 로그를 수동 업로드/조회 형태로 수용 가능(기관별 상이성 흡수).
  • Manual Fallback: 태그 분실 시 교사/기사 앱에서 [이름 터치]로 수동 체크 (예외처리).
* 법규 리스크(하차 확인 의무/제재): 법제처 보도자료 기준 (Ref-6)
③ Parent Link (학부모 앱) App
  • 폐쇄형 인증: 초대코드 → 자녀 매칭 → 관리자 승인 3단계.
  • 이동 이벤트 알림: Gate-Out/Boarding/Drop-off 푸시 + 예외(미탑승/미하차) 즉시 알림.
  • 서류 디지털화: 투약의뢰서/결석계/귀가동의서 앱 제출 (종이 서류 0).
  • Clean AD: 지역 기반 교육정보(수익 모델) — 파일럿에서는 기본 OFF.

06. Roadmap 단계별 실행 계획

Phase 1. 검증 (M1~4)

MVP & Pilot

Target: 5~10개소

  • 핵심 기능(태깅/일지/문서) 개발 완료
  • 단설 유치원 5곳 파일럿 테스트
  • NFC 인식률 및 데이터 정합성 검증
  • NEIS 입력용 산출물(복붙/서식) 검증
  • * 매출 목표: 0원 (Free Pilot)
Phase 2. 진입 (M5~12)

Market Entry

Target: 50~100개소

  • 유료화 전환 (구독 모델 시작)
  • "장비값 0원" 입학 시즌 캠페인
  • 교육지원청 시범사업 제안
  • 학부모 앱 기능 확장(서류 제출/알림)
  • * 매출 목표: 2~4억 원
Phase 3. 확장 (Year 2)

Scale-Up

Target: 300+ & Elementary

  • 초등 돌봄/늘봄교실 패키지 런칭
  • 조달청(벤처나라) 등록

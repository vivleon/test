01. Project Canvas 문제 정의 및 솔루션

🚫 Pain Points (문제)

  • 안전 사각지대: 하차벨(버스)과 교실 출석부(NEIS)가 연동되지 않아 '중간 이탈' 위험 존재.
  • 행정 업무 과중: 교사 업무 40%가 단순 입력(투약, 일지, 품의).
  • 비용 장벽: 5학급 미만 소규모 유치원은 고가 장비(비콘/리더기) 설치 불가.

💡 Scholix Solution (해결)

  • AI Admin Core: 음성 한 줄로 [안전일지+투약의뢰+보고서] 자동 생성.
  • Dual Gate Logic: 버스(이동) + 교문(도보) 태깅 데이터를 크로스 체크.
  • Zero-Hardware: 교사/기사 스마트폰 = 리더기. (도입비 0원).

02. 3 Core Solutions 핵심 기능 및 예외 처리

① AI Admin (행정) Core
  • 전자출석부: 태깅 데이터 → 법정 서식 자동 매핑.
  • AI Safety Report: 사고 발생 시 음성(STT) → 경위서/보고서 변환.
  • 평가 증빙: 평가지표별 사진/문서 자동 분류.
② Dual Gate (안전) Patent
  • Gate-to-Gate: 버스 승하차 + 현관 통합 관제.
  • Cross Check: "하차O / 입실X" 시 즉시 경보.
  • Manual Fallback: 태그 미지참 시 앱 내 [수동 출석] 버튼으로 예외 처리.
③ Parent Link (앱) App
  • 안심 알림: 위치 기반(정문/버스) 정확한 알림.
  • 민원 디지털화: 투약의뢰서, 결석계, 귀가동의서 앱 제출.
  • Clean AD: 지역 기반 교육정보(수익 모델).

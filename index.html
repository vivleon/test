01. Project Canvas

🚫 Problem (문제)

  • 비용 장벽: 단설 유치원은 차량 단말기(대당 50만원) 및 통신비 예산 부족.
  • 업무 과중: 운행일지 수기 작성 → 엑셀 재입력의 비효율 반복.
  • 안전 공백: 사고 발생 시 경위서 작성이 늦어 '골든타임' 증빙 누락.

💡 Solution (해결)

  • Zero-Hardware: 기사님 폰 앱(Driver App)만으로 관제/일지 100% 자동화.
  • Voice AI: "철수가 넘어짐" 말하면 육하원칙 보고서 자동 생성.
  • Ad-Revenue: 폐쇄형 학부모 앱 광고 수익으로 서버비 상쇄.

02. 3대 핵심 솔루션

① Core (행정/안전)
  • 평가 증빙 자동화: 지표별 사진/서류 자동 분류.
  • AI Safety Pack: 사고 현장 녹음(STT) → 법정 서식 자동 변환.
  • 타임라인 리포트: 발견-조치-연락 전 과정 증빙 출력.
② Transit (통학)
  • 무설치 관제: 운전자 폰 GPS로 위치/경로 추적.
  • 자동 운행일지: 거리/시간/정차 데이터 법정 서식 매핑.
  • AI 안전점수: 급정거/과속 센서 분석 (교육청 보고용).
③ Parent (학부모)
  • 폐쇄형 인증: 초대코드+관리자 승인 (외부인 차단).
  • 실시간 위치: 셔틀 도착 알림 (Push).
  • Clean AD: 하단 배너에 육아/교육 정보 제공 (수익화).

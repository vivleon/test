03. 3 Core Solutions 핵심 기능 상세

① AI Admin (행정) Core
  • 전자출석부: 태깅 데이터 → 법정 서식(NEIS 연동형) 자동 매핑.
  • AI Safety Pack: 사고 발생 시 음성(STT) → 육하원칙 경위서/보고서 변환.
  • 평가 증빙 OS: 평가지표별 사진/문서 자동 분류 및 저장.
② Triple Check (안전) Logic
  • Triple-Check: [교실(하원) → 버스(탑승) → 집(하차)] 3단계 추적.
  • Cross Check: "게이트 아웃 OK, 탑승 미확인" 시 즉시 경보.
  • Manual Fallback: 태그 분실 시 교사/기사 앱에서 [수동 체크] (예외처리).
* 법규 리스크(하차 확인 의무/제재): 법제처 보도자료 기준 (Ref-6)
③ Parent Link (앱) App
  • 안심 알림: "탑승/하차" 푸시 알림 + 폐쇄형 인증(초대코드).
  • 민원 디지털화: 투약의뢰서, 결석계, 귀가동의서 앱 제출 (종이 서류 0).
  • Clean AD: 지역 기반 교육정보(수익 모델).

핵심 데이터 정합성 규칙(Triple-Check Engine) Rules

Reconciliation Rules (MVP 우선순위 포함)

Rule-1 (High): GATE_OUT=TRUE & BOARDING=FALSE within T minutes
- 즉시 알림: Teacher + Admin + Driver
- 차량 출발 전: Driver App "출발 차단" (soft-lock)
- 예외 처리: Admin Override(사유 필수) → Audit

Rule-2 (High): BOARDING=TRUE & DROP_OFF=FALSE at route end
- 종점/노선 종료 시 "미하차" 목록 고정 노출
- Driver must resolve: Drop-off scan or Manual fallback + photo optional
- Parent notification: "확인 중" 상태 유지(추정 표현 금지)

Rule-3 (Medium): Duplicate scan / Out-of-order events
- 마지막 이벤트 기준 정렬 + 중복 제거
- 수동 수정은 Admin만 가능(사유/승인 로그)

Rule-4 (Ops): Offline queue replay
- eventId(ULID) + idempotencyKey
- 서버는 idempotent upsert 처리(중복 수신 방지)
